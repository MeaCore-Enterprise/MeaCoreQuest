# MeaCore Quest

Un RPG de acción 2D estilo arcade con mecánicas de Solo Leveling, construido con Godot 4.

## Características

- **Combate arcade**: Ataques básicos, combos de 3 golpes, dash evasivo con i-frames
- **Sistema de clases**: Guerrero (melee), Mago (rango mágico), Arquero (rango físico)
- **Estilo Solo Leveling**: Status Window con STR/DEX/INT/CON/VIT, fórmulas de daño con diminishing returns
- **Misiones**: Sistema de misiones progresivas con recompensas adaptadas a tu clase
- **Equipamiento**: Armas, armaduras y escudos con stats y rarezas
- **Mundo abierto**: Mapa procedural con biomas: pradera, bosque, cementerio y arena de boss
- **Proyectiles**: Sistema con piercing y área de efecto
- **Hit-stop**: Congelación de frames al impactar para sensación arcade
- **Sonido 8-bit**: Efectos de sonido generados proceduralmente

## Controles

| Tecla | Acción |
|-------|--------|
| W/A/S/D o Flechas | Moverse |
| Click izquierdo | Atacar al objetivo |
| Click derecho | Dash evasivo |
| 1 / 2 / 3 | Habilidades |
| 4 | Poción de HP |
| 5 | Poción de MP |
| Espacio | Ataque básico |
| Tab | Ciclar objetivo |
| I | Inventario |
| C | Personaje |

## Cómo jugar

1. Selecciona tu clase y distribuye tus stats iniciales
2. Habla con el Elder en la plaza para obtener tu primera misión
3. Derrota slimes en la pradera para subir de nivel
4. Mejora tus stats y habilidades al subir de nivel
5. Equipa mejores armas y armaduras
6. Enfréntate al Señor Oscuro en la arena del norte

## Requisitos

- Godot 4.4+

## Compilar

```bash
git clone https://github.com/tuusuario/MeaCore-Quest.git

```
